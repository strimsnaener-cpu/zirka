# «Зірка оживає» — різдвяна онлайн-майстерня Lava Candles

Мобільний веб-застосунок для набору «дерев’яна восьмикутна зірка 17×17 см + підставка «Зимове село»».
Користувач заходить з QR-коду на коробці → бачить 3D-вітрину → створює свій орнамент → розписує зірку
крок за кроком → зберігає PNG для соцмереж. Фоном — колядки.

Чистий HTML/CSS/JS (ES-модулі) + Three.js (лежить у `vendor/`, з інтернету нічого не тягне, крім шрифтів Google).
Збирати нічого не треба.

## Запуск

```powershell
node server.mjs
```
Відкрити http://localhost:5173. (Подвійний клік по `index.html` не спрацює — браузер не дає ES-модулям працювати з `file://`.)

Для публікації — завантажити всю папку на будь-який статичний хостинг (GitHub Pages, Netlify, Cloudflare Pages).
QR-код на коробці веде на `https://<ваш-домен>/#showcase`.

## Куди класти свої файли

| Що | Куди | Примітка |
|---|---|---|
| Фото зірки спереду | `assets/star-front.png` | квадрат 1:1, кінчики променів торкаються країв кадру, знято строго спереду |
| Фото зірки ззаду | `assets/star-back.png` | так само |
| Фото підставки | `assets/village-stand.png` | PNG **з прозорим фоном**, строго спереду, обрізане впритул — з нього автоматично обводиться 3D-силует |
| Текстура фанери | `assets/textures/plywood-face.jpg` | просто дерево крупним планом (без виробу); тайлиться, масштаб — `ASSETS.textures.repeatCm` |
| Торець фанери | `assets/textures/plywood-edge.jpg` | зріз листа крупно (видно шари шпону) |
| Референси для підгонки | `assets/reference/…` | список — `ASSETS.references`, з’являються в `calibrate.html` |
| Колядки | `audio/01-shchedryk.mp3` … `04-dzvinochky.mp3` | назви/шляхи — у `js/config.js → PLAYLIST` |
| Галерея «Набір у реальності» | `assets/photos/` | список — у `js/config.js → ASSETS.gallery` |

Поки файлів немає, усе працює на заглушках: процедурне дерево, силует підставки обводиться з макета села,
а плеєр грає синтезовану «музичну скриньку». Щойно файл з’являється — він підхоплюється автоматично.
Тонке зміщення фото на 3D-формі — `ASSETS.calib`.

## 3D-модель

- **Зірка** — суцільне тіло з фанери: товщина `STAR.thicknessCm`, фаска `STAR.chamferCm` по краю й по 8 прорізах.
  Лицьовий бік — живий розпис із майстерні (той самий SVG, з урахуванням поточного кроку), золото — металеве.
- **Підставка** — плаский силует із фанери (`STAND.thicknessCm`) у пазу платформи `STAND.foot`; перед ним у своєму
  пазу — паличка зірки (`STAND.stick`). Контур обводиться автоматично з `village-stand.png` (1-в-1 з виробом)
  або з макета села. Ширина силуету з фото — `STAND.widthCm`, висота центру зірки — `STAND.starCenterCm`.
- Керування — OrbitControls: вільне обертання на 360°, щипок/колесо — зум, через 3 с без дотиків — знову крутиться сама.
- У майстерні кнопка **3D** на сцені показує розпис прямо на моделі; у режимі «крок за кроком» видно лише вже розписані шари.

## Підгонка контуру під реальний виріб

1. Сфотографуйте зірку строго спереду, покладіть як `assets/star-front.png`.
2. Відкрийте `http://localhost:5173/calibrate.html`, суміщайте фото з червоним контуром повзунками.
3. Скопіюйте результат у `js/config.js → STAR`. SVG-конструктор, покроковий розпис, PNG і 3D-форма
   перебудуються від цих чисел самі.

`dev-gallery.html` — службова сторінка: всі 17 орнаментів і 3 варіанти села на одному екрані.

## Структура

```
index.html            розмітка трьох екранів + плеєр
css/styles.css        дизайн (mobile-first)
js/config.js          ← ЄДИНИЙ файл налаштувань: фото, текстури, 5 фарб, плейлист, геометрія зірки й підставки
js/geometry.js        форма зірки, прорізи, «пензлі» (пелюстка, листок, крапка, іскра…)
js/ornaments.js       17 орнаментів (9 базових + 8 українських народних), пресети, порядок шарів і висихання
js/village.js         підставка «Моє різдвяне село» + 3 варіанти оформлення
js/render.js          SVG-рендер «розфарбовуваних» об’єктів по шарах
js/compose.js         композиція «зірка на паличці + село» (майстерня, фінал, PNG)
js/workshop.js        Режим А (створюю) і Режим Б (крок за кроком): зум, контури, таймер
js/viewer3d.js        3D-модель на Three.js + OrbitControls (вітрина і «3D» у майстерні)
js/trace.js           автообведення силуету з PNG/SVG (контур → 3D-форма)
js/player.js          плеєр колядок (+ синтез-заглушка)
js/export.js          PNG 1080×1350
js/store.js           стан і збереження вибору в браузері
calibrate.html        підгонка контуру під фото
server.mjs            локальний сервер без залежностей
```

## Як додати свій орнамент

У `js/ornaments.js` скопіюйте будь-який дизайн. Кожен елемент:
`{ layer, slot, rep, svg }` — `layer` визначає крок розпису (`outline`, `base`, `ornament`, `fine`, `gold`),
`slot` — що фарбується однією фарбою, `rep: 'all'` повторює елемент на всіх 8 променях,
а символ `@` у `svg` замінюється кольором. Порядок кроків — `order`, хвилини висихання — `dry`.
Для темної основи (див. «Морозний візерунок») основа йде першою, а контури — після висихання.
Назви кроків можна перевизначити полем `stepTitles`, а підпис на картці — полем `origin`.

### Українські народні мотиви (рівні 1–3)

| Орнамент | Походження | Порядок кроків |
|---|---|---|
| Подільська геометрія | ромби з «серцем», Поділля | контури → основа → червоні ромби → чорні серця → золото |
| Гуцульська кривулька | Гуцульщина | чорна основа → контури → грані й ромби → біла кривулька → золото |
| Восьмикутна ружа | знак Сонця | контури → основа → червоні пелюстки → зелені пелюстки → золота ружа |
| Різдвяний павук | солом’яні павуки | зелена основа → контури → вставки → намистинки → золоті соломинки |
| Вишиванка | вишивка хрестиком | контури-сітка → основа → чорні хрестики → кольорові → золото |
| Косівська кераміка | Косів | контури → біле тло → листки й квіти → чорний контур → золото |
| Петриківська калина | Петриківка | чорна основа → контури → грона й листя → відблиски → гребінчик |
| Писанкова зоря | сорококлинець | чорна основа → контури → червоні клини → білі клини → золото |

Усі вписані у форму променя (`halfW(t)`), не заходять на прорізи й використовують лише 5 фарб набору.
